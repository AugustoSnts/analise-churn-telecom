# Pasta `data/`

Esta pasta guarda a base de dados do projeto. O CSV **não é versionado** no Git: É necessário baixar a base diretamente da fonte.

## Como obter a base

1. Acesse a página da base no Kaggle:
   https://www.kaggle.com/datasets/blastchar/telco-customer-churn
2. Leia a descrição e as condições de uso indicadas pelo publicador.
3. Baixe o arquivo CSV (nome original mais comum: `WA_Fn-UseC_-Telco-Customer-Churn.csv`).
4. Salve nesta pasta com o nome **`WA_Fn-UseC_-Telco-Customer-Churn.csv`**
   (ou, se preferir manter o nome original, altere a variável `CAMINHO_CSV` no notebook).

## 

- **Nunca edite o CSV original.** Toda limpeza é feita em memória, no código, priorizando a integridade da fonte original.
